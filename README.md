# RizTech App Pages

Official **privacy policies** and landing pages for RizTech Android apps, hosted via GitHub Pages.

## Live URL
**https://rizwantech-dev.github.io/rizwantech-pages/**

## Apps

| App | Package ID | Privacy Policy |
|-----|-----------|----------------|
| 📚 Bookshelf | `com.riztech.bookshelf` | [Privacy Policy](bookshelf/privacy-policy.html) |

## Structure

```
rizwantech-pages/
├── index.html                        ← Landing page listing all apps
├── bookshelf/
│   └── privacy-policy.html           ← Bookshelf privacy policy
└── <future-app>/
    └── privacy-policy.html           ← Future app pages go here
```

## Adding a New App's Privacy Policy

1. Create a folder: `<app-name>/`
2. Add `privacy-policy.html` inside it
3. Add a card for it in `index.html`
4. Push to `main` — GitHub Pages auto-deploys
